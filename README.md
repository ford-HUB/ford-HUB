## 🚀 Projects I've shipped

### <img src="https://cdn.jsdelivr.net/gh/devicons/devicon@latest/icons/nestjs/nestjs-original.svg" width="20" height="20" align="top" /> [CARES Infra](https://github.com/ford-HUB/cares-infra)

A distributed community-services platform: a NestJS modular monolith of 30+ domains — assistance requests, residential needs, donations, payments, certificates, event attendance, support tickets, access control, audit logs, system diagnostics — sitting in front of six Python AI microservices, each independently Dockerised.

| Microservice | Does | Built with |
| --- | --- | --- |
| `fr-service` | Face recognition for identity verification | InsightFace · ONNX Runtime · OpenCV |
| `ocr-service` | Document and ID text extraction | Tesseract · PyMuPDF · Pillow |
| `nlp-service` | Semantic text matching and embeddings | PyTorch · sentence-transformers |
| `ucid-service` | ID document classification | TensorFlow · OpenCV |
| `gps-validator-service` | Geospatial boundary validation | Shapely · pyproj |
| `decision-service` | Eligibility scoring and ranking | scikit-learn · NumPy |

> **Server:** NestJS · Prisma · PostgreSQL · BullMQ · Redis · Socket.IO · AWS S3 · Passport (JWT + Google OAuth + JWKS)
> **Site:** React · TypeScript · Vite · Tailwind CSS · Mapbox GL + Turf.js · Chart.js · Recharts · Zustand
> **Infra:** Docker Compose (separate dev and prod stacks)

### <img src="https://cdn.jsdelivr.net/gh/devicons/devicon@latest/icons/electron/electron-original.svg" width="20" height="20" align="top" /> [NXLogSync](https://github.com/ford-HUB/nxlogsync)

A desktop app with a companion server that takes the repetitive work out of timesheets. You log your day once and NXLogSync drives the work-log site for you on a schedule — handling allocations, overtime rows, and endorsement. Each synced day is cleared and rewritten in full, so the timesheet always matches what you logged. It also generates the monthly and yearly reports the team needs, sends reminder emails, and ships with break-time mini-games (typing duels with a live leaderboard, Tetris, an aim trainer).

> **Desktop:** Electron · React · TypeScript · Vite · Tailwind CSS · shadcn/ui · Zustand
> **Server:** NestJS · Prisma · PostgreSQL · Socket.IO · Puppeteer
> **Reports:** ExcelJS · PDFKit · jsPDF

### <img src="https://cdn.jsdelivr.net/gh/devicons/devicon@latest/icons/laravel/laravel-original.svg" width="20" height="20" align="top" /> [UISP × PayMaya Microservice](https://github.com/ford-HUB/uisp-paymaya-microservice)

Secure middleware bridging **PayMaya** payment processing with the **UISP** ISP management system, automating the path from invoice to reconciliation. Validates invoices against the UISP API before creating a PayMaya checkout session, then handles the webhook back.

Built around the parts that matter in payments: **server-to-server verification** (never trusting the webhook payload alone), **HMAC signature validation**, **idempotency keys** so a payment is never posted twice, **exponential-backoff retries** through a queue when the UISP API is down, and a `webhook_logs` audit trail. No card data touches local servers — PayMaya keeps the PCI scope.

> Laravel (API-only) · MySQL · Laravel Horizon · Redis · Docker (Nginx + PHP-FPM)
